# Меню на неделю — Александр (v1.7 ккал ~1900–2200)

Ориентир: твои привычные продукты · белок 160–180 · крахмал 250–300 г варёного · хлеб ≤1 кусок.

Порции крахмала — **варёный вес**. Соя — считать размоченную отдельно от сухой.

---

## Закупка (на тебя)

| Продукт | Кол-во |
|---|---|
| Творог 5% / дом. | ~2.2–2.5 кг |
| Яйца | 30–35 шт |
| Молоко | ~0.5–0.7 л (к творогу) |
| Чечевица / фасоль / горох | 4–5 порций (сухая или консервы) |
| Макароны ц/з + гречка | по ~400–500 г сухих на нед |
| Картофель | ~1 кг |
| Хлеб зерновой | 5–7 кусков |
| Овощи / салат / кабачки / помидоры | по аппетиту |
| Яблоки / сливы / земляника с сахаром | умеренно |
| Конопляный / соевый протеин | добор вечером при недоборе белка |
| Кефир 3.2% | 1–1.5 л (не 900 мл за раз) |
| Чудо / Агуша | по желанию, небольшие порции |

---

## Каркас дня (повторяется)

1. **Завтрак:** творог 300–350 + молоко 50 + 1 ст.л. ягода с сахаром *или без* + хлеб 50 г **И/ИЛИ** 2–3 яйца  
2. **Обед:** бобовые 250–300 + крахмал **250–300** + салат (масло мерить) ± 1–2 яйца  
3. **Ужин:** крахмал поменьше **или** яйца + овощи + творог 150–200  
4. **Добор:** если белка <150 к 20:00 → протеин 2–3 ст.л. или творог 150

## Чего избегать «по привычке»

| Было | В меню |
|---|---|
| Макароны 350–400 | **250–300** |
| Кефир 900 | **≤400** |
| Пирог 200 | **≤70** или без |
| Хлеб 100 + кусок утром | **один** кусок за день |
| Соя «100 г» без пометки | писать **размоченная / сухая** |
| Ночной творог + сироп часто | ок редко; лучше добор днём |

---

## Связь с ходьбой

В дни **Вт / Чт / Вс** ходьба — часть тренировки: не «добор еды после», а активность.  
После длинной ходьбы **не** компенсировать пирогом — белок + овощи.
